🏏 IPL Data Analysis Project

📌 Overview

This project is a beginner-friendly Exploratory Data Analysis (EDA) of the Indian Premier League (IPL) dataset.
The goal of this project is to understand cricket data using Python and derive meaningful insights using data visualization.

🎯 Objectives
Analyze IPL match data
Identify trends in team performance
Understand player contributions
Visualize key statistics using graphs

🛠️ Tools & Technologies Used
Python 🐍
Jupyter Notebook 📒
NumPy
Pandas
Matplotlib
Seaborn


📊 Key Analysis Performed
Total matches played per season
Most successful IPL teams
Toss decision impact (bat/field first)
Top winning teams
Top players (batsmen & bowlers)
Match outcomes based on toss decisions


📈 Visualizations Included
Bar charts 📊
Count plots


📂 Project Structure
IPL-Analysis/
│
├── IPL_Analysis.ipynb      # Main Jupyter Notebook
└── README.md               # Project documentation


🚀 Key Insights
Certain teams dominate IPL history consistently
Toss decision has a measurable impact on match outcomes
A few players contribute significantly to team success
Winning patterns vary across seasons
